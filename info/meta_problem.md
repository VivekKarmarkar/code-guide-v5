# The Meta-Problem: Losing Touch with Code in the Age of AI-Assisted Development

## The Problem

There is a meta-problem emerging in AI-assisted development: the better you get at steering Claude Code at the systems level, the more the actual code becomes a black box. You ship faster, but the mental model of *what's actually in the box* gets thinner.

Claude Code programmers are becoming proficient in a new kind of programming — breathing slash commands, inhaling MCPs, doing systems-level thinking, and shipping at unprecedented speed. But this proficiency comes at a cost: an organic disconnect from the core code-level understanding.

## The Solution

A piece of software that:

1. **Takes a codebase** — via a public GitHub URL or a local folder path
2. **Agentically explores it** — not just static analysis, but intelligent traversal
3. **Produces a layered visual representation** — starting zoomed out (architecture, systems, relationships) and letting you drill down toward the actual syntax and logic
4. **Bridges the gap** between "I know what this system does" and "I know how this code works"

## Key Framing

- It is NOT a documentation tool — it is a **reconnection tool**
- It is NOT for onboarding strangers to a codebase — it is for **the person who built it** but at a higher altitude
- The visual hierarchy mirrors how understanding actually works: system -> module -> function -> line
- Understanding progresses from system-level and visual to code-level and syntactic

## Dual Purpose

The tool serves dual purposes:
- **Own projects** (local and GitHub) — reconnecting with code you shipped fast using Claude Code
- **Other people's projects** (GitHub) — building understanding of unfamiliar codebases from the top down
